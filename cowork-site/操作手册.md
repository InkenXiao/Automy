# 玄圃 · 智创 CoWork 操作手册

> 适用对象：平台最终用户与管理员。
> 平台由统一入口页（8090）与三大子系统组成：项目管理智能体工作平台 pro-cowork（8091）、知识工坊 rag-cowork（8092）、技链工坊 mcp-cowork（8094）。

---

## 一、系统入口与账号

### 1.1 统一入口

浏览器访问 `http://<服务器地址>:8090/`，进入「玄圃 · 智创」统一入口页，点击卡片进入对应子系统：

| 卡片 | 子系统 | 直达地址 | 用途 |
|------|--------|----------|------|
| 项目 Project Agent | pro-cowork | `http://<服务器地址>:8091/` | 项目协同 + 智能体工作台 |
| 知识 Knowledge Base | rag-cowork | `http://<服务器地址>:8092/` | 知识库构建与 RAG 问答 |
| 连接 MCP Gateway | mcp-cowork | `http://<服务器地址>:8094/` | MCP 服务管理与在线测试 |

### 1.2 登录与密码

- 三个子系统**账号体系统一**，均使用**姓名**登录（账号由管理员预先创建，未注册用户无法登录）。
- **首次登录**：若账号未设置密码，输入姓名后直接进入系统。
- **设置/修改密码**：登录后在页面右上角点击「设置密码」（pro-cowork 为「修改密码」）。设置后再次登录须输入密码。
- **退出登录**：页面右上角「退出」按钮。

## 二、项目管理智能体工作平台（pro-cowork :8091）

界面左侧导航为「**首页** + 三组视图」：**智能工作台**（任务/智能体/技能）、**项目台**（进度计划/项目会议/项目周报/每周任务/项目成员/个人周报/操作日志）、**设计台**（智能体设计/技能设计/记忆维护）。

### 2.1 首页 —— 个人看板

登录后默认进入首页，顶部为时段问候 + 日期周次 + 当前激活项目，下方为小部件看板：

| 小部件 | 内容 |
|--------|------|
| 我的待办 | 本周指派给我的未完成工作任务 |
| 长任务结果 | 最新执行的长任务及结果摘要，点击可回放执行过程 |
| 本周任务 | 当前项目本周进行中的工作任务 |
| 延误进度 | 已延期或超期未完成的进度计划任务 |
| 常用数字分身 | 收藏的智能体，点击直接进入对话 |

点击右上角「⚙ 自定义看板」可设置各小部件的**显示/隐藏与排序**，并收藏常用数字分身；配置按登录人隔离保存在浏览器本地，不影响他人。

### 2.2 工作台 —— 任务

日常 AI 协作的主入口，操作流程：

1. **描述任务**：在输入框用自然语言描述要做什么（如"生成本周项目周报""把这段会议纪要整理成议程"）。
2. **意图识别**：系统自动识别任务归属的项目 / 数字分身（智能体）/ 技能；未命中时弹出选择窗口，手动点选即可。
3. **查看执行**：执行过程与输出实时展示在执行窗口（支持断线后重进续看）。
4. **持续补充**：在任务会话的补充区继续输入内容驱动 AI 接着做，可追加附件与技能，上下文连贯。

**多模态附件**（所有 AI 对话窗口通用）：

| 附件类型 | 操作方式 | 背后能力 |
|----------|----------|----------|
| 图片 | 「＋」上传 或 Ctrl+V 直接粘贴 | 图像识别（视觉多模态模型） |
| PDF / 文档 | 「＋」上传 或 Ctrl+V 粘贴 | 文档解析（电子 PDF 秒级解析；扫描件走 MinerU 算力网关，较慢属正常） |
| 录音（mp3/wav/m4a 等） | 「＋」上传 | 会议纪要生成（ASR 转写 + 纪要流式生成） |

### 2.3 工作台 —— 智能体 / 技能

- **智能体**：查看与调用平台内置的五大智能体及自建智能体，支持对话式交互：

| 智能体 | 能做什么 |
|--------|----------|
| 进度管理助手 | 查询/维护进度计划，识别延期风险 |
| 会议管理助手 | 会议记录管理、录音转写与纪要生成 |
| 周报编写助手 | 项目周报编写；**个人周报**：查询填报情况（催报）、代填/更新、AI 生成周报概括 |
| 工作计划助手 | 制定周工作计划与每周任务 |
| 知识库管理助手 | 对话式维护 rag-cowork 知识库（见 2.3.1） |

- **技能**：查看可用技能（会议纪要生成、文档解析、图像识别、项目周工作小结、周报草稿生成、个人周报填报扫描、延期任务扫描、会议议程准备、周计划生成），可手动试运行。

#### 2.3.1 知识库管理助手 —— 对话式知识库维护

无需切换到 rag-cowork 页面，在与「知识库管理助手」的对话中即可完成知识库全生命周期操作：

1. **建库**：如"新建一个项目级知识库《XX项目文档》关联当前项目"（五级可见性：公司/部门/项目/个人/外接，同 3.1）；
2. **传文入库**：如"把这段内容整理成《规范.md》上传到《XX》知识库并解析"（适合小文本文件；大文件建议走 rag-cowork 网页上传）；
3. **状态巡检**：如"看看《XX》库里文件都解析完了吗"——列出待解析/解析中/完成/失败状态与失败原因；
4. **检索验证**：如"在《XX》库里检索一下××"或"问《XX》库：×××"——验证入库质量；
5. **清理维护**：如"重新解析《XX》库里的 xx 文件"（幂等重跑）、"删除《XX》库里的 xx 文件"。

> 助手以你的登录身份操作（身份自动透传给 rag-cowork），知识库五级可见性权限与 rag-cowork 页面一致——只能看到并操作你有权限的知识库。

### 2.4 项目台 —— 项目协同数据

| 视图 | 功能 |
|------|------|
| 进度计划 | 项目甘特任务维护：按阶段（有得用/用起来/用得好）分组，支持里程碑标记与状态切换 |
| 项目会议 | 会议记录 + 议程项管理；上传录音可自动转写并生成纪要 |
| 项目周报 | 周报编写（KPI/本周进展/下周任务/风险四段式），支持批量保存与导出 |
| 每周任务 | 周工作任务执行层，可从周报"下周任务"批量生成，登记计划/实际工时 |
| 项目成员 | 维护项目成员（角色/岗位、入组时间、状态）—— 仅项目经理可操作 |
| 个人周报 | 每人填写本周工作内容（按天）与下周计划，支持 Excel 导出；右栏「周报概括」面板可点「✨ AI 生成概括」按本周明细自动归纳 2-3 段（本周工作 + 下周计划），可自由修改后保存随周报归档 |
| 操作日志 | 操作留痕与 LLM token 消耗统计；项目经理可见全部，普通成员仅见本人 |

> **权限说明**：项目经理可维护项目成员并查看全部操作日志；非经理成员仅可查看/填写本人周报与本人日志；未分配项目的用户在项目类视图中看不到业务数据。

### 2.5 设计台 —— 平台能力扩展

| 视图 | 功能 |
|------|------|
| 智能体设计 | 构建/调试自定义智能体：配置提示词、挂载工具与技能，调试窗口带执行 Trace |
| 技能设计 | 编排技能工作流（数据/API/通知等步骤），试运行验证后发布 |
| 记忆维护 | 查看/测试智能体记忆；记忆**按项目隔离**，对话时自动注入当前项目记忆 + 通用记忆 |

## 三、知识工坊（rag-cowork :8092）

三栏布局：左侧**知识库树**、中间**文件列表**、右侧**RAG 检索测试**。

### 3.1 新建知识库

点击左栏「+ 新建」，填写：

| 字段 | 说明 |
|------|------|
| 名称 | 知识库名称 |
| 级别 | 五级可见性体系，见下表 |
| 关联项目 | 级别选"项目级"时出现，关联 pro-cowork 中的项目 |
| 所属部门 | 级别选"部门级"时出现，与用户部门字段匹配 |
| 描述 | 用途说明 |

| 级别 | 可见范围 |
|------|----------|
| 公司级 | 全员可读 |
| 部门级 | 本部门成员可读写 |
| 项目级 | 关联项目成员可读写 |
| 个人级 | 仅自己 + 被授权人 |
| 外接级 | 仅被授权人 |

> 个人级/外接级知识库可通过文件列表上方的**授权**入口，按用户授予「可读 / 可写 / 管理」权限。

### 3.2 上传与解析文档

1. 在左栏选中目标知识库。
2. 中栏拖拽文件到上传区（或点击选择），支持 **PDF / Word / Excel / PPT / TXT / MD / 图片 / 语音（mp3 wav m4a 等）**。
3. 上传后文件进入解析队列，关注"状态"列：待解析 → 解析中 → 完成 / 失败（失败可查看原因并重试）。
4. 解析完成后"分块"列显示分块数量，文档即进入可检索状态。

> 提示：扫描件 PDF 走 MinerU 深度解析，耗时数分钟属正常现象；重解析是幂等操作（自动清理旧数据后重建），可放心重复执行。

### 3.3 RAG 检索测试

右栏输入问题（Ctrl+Enter 发送），两个开关：

- **检索模式**：`hybrid 混合检索`（推荐，实体+关系双路）/ `local 实体聚焦` / `global 关系聚焦`
- **检索范围**：`当前知识库` / `全部可见知识库`

结果区展示 AI 生成的答案与命中依据，可用于验证入库质量。

## 四、技链工坊（mcp-cowork :8094）

三栏布局：左侧 **MCP 服务**、中间**工具清单 + 测试台**、右侧**调用统计**。

### 4.1 注册 MCP 服务

1. 点击左栏「+ 注册」。
2. 填写名称（如 `rag-cowork`）与 streamable-HTTP 端点地址（如 `http://localhost:8093/mcp`）。
3. 保存后平台自动健康检查并同步工具清单。

左栏每张服务卡片显示在线状态点与工具数，卡片上的操作按钮：

| 按钮 | 作用 |
|------|------|
| 测试 | 选中该服务，中栏展示其工具卡片进入测试 |
| 记录 | 弹窗查看该服务的最近调用记录（工具/状态/耗时/时间） |
| 健康检查 | 手动探测服务在线状态与工具数 |
| 同步工具 | 重新拉取该服务的工具清单 |
| 编辑 / 删除 | 修改服务配置；删除需二次点击确认 |

### 4.2 在线测试工具

1. 左栏选中服务，中栏展示其工具卡片。
2. 点击工具卡片，查看**参数 Schema**。
3. 在「调用参数 (JSON)」编辑框中按 Schema 填写参数，点击**调用**，结果展示在下方结果框。
4. 填写"用例名称"后点**存为用例**，保存本次参数与结果；已存用例可一键**回放**（自动填充参数再次调用）。

### 4.3 调用统计

右栏实时展示：调用总量/成功率等统计卡片、工具调用分布（Top20）、最近调用记录（工具/状态/耗时/时间），用于观测各 MCP 服务的使用情况与性能。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 提示"用户未注册" | 联系管理员在系统中创建同名账号（pro-cowork 的项目成员 / rag、mcp 的系统用户） |
| 忘记密码 | 联系管理员重置；未设密码的账号可直接姓名登录 |
| 看不到某些知识库 | 确认知识库级别与自身部门/项目归属；个人级、外接级需库管理员授权 |
| 文档解析失败 | 查看文件列表中的错误信息；扫描件确认 MinerU 服务在线；修正后重新解析即可（幂等） |
| 上传的图片/录音没有 AI 响应 | 确认对应模型通道已配置（图像识别走 VISION 通道，录音走 ASR 服务） |
| MCP 工具调用超时 | 检查目标 MCP 服务是否在线（左栏服务状态），必要时点"同步"重建连接 |
